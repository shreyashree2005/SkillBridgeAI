# 🌉 SkillBridge AI

> **Learn • Teach • Collaborate • Build • Get Hired**

SkillBridge AI is an AI-powered platform for students and early-career
developers to learn skills, teach others, collaborate on real projects,
build a portfolio, and get hired — combining ideas from LinkedIn, Fiverr,
Coursera, GitHub, and Discord, with an AI career assistant at the core.

---

## ✨ Core Features (planned)

- 🔐 Authentication & user profiles
- 🧑‍🎓 Skill tracking & skill-gap analysis
- 📚 Learning & teaching modules
- 🤝 Team finder & real-time chat
- 📄 AI resume analyzer & match scoring
- 🧭 AI-generated learning roadmaps
- 💬 AI career chatbot & interview prep
- 📊 Personalized career dashboard

## 🏗️ Architecture

This is a **monorepo** with three main parts:

| Folder        | Tech                | Responsibility                          |
|---------------|---------------------|------------------------------------------|
| `client/`     | React               | User interface (frontend)                |
| `server/`     | Node.js + Express   | Business logic, database, REST APIs      |
| `ai-service/` | Python + FastAPI    | Machine-learning & AI features           |

Supporting folders: `datasets/` (seed data), `assets/` (shared media),
`docs/` (architecture & API documentation).
